Commandes d'installation

  1. mkdir scihub-prisma-mcp && cd scihub-prisma-mcp
  2. npm init -y
  3. npm i @modelcontextprotocol/sdk axios cheerio typescript @types/node
  4. npx tsc --init
  5. npx tsc && node build/index.js

Integration Claude Desktop

Fichier claude_desktop_config.json :

{
  "mcpServers": {
    "scihub-prisma": {
      "command": "node",
      "args": ["/chemin/vers/scihub-prisma-mcp/build/index.js"]
    }
  }
}
